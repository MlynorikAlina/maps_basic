# maps_basic

Инструмент для генерации векторных тайлов из формата OSM PBF, настройки стилей и рендеринга карт.

```bash
git clone git@gitserver:/home/git/git/maps_basic.git --recurse-submodules
```


## Структура проекта

* `data/` — данные для генерации векторных тайлов (скрипты, файлы конфигурации, некоторые общие данные).
* `styles/` — стили, шрифты, спрайты и скрипт для настройки путей.
* `maps_basic/` — консольное приложение для автоматизации всего процесса.

---

## Быстрый старт

Перед началом работы необходимо установить зависимости. Запустите скрипты установки из корневой директории:

```bash
chmod +x install_tilemaker.sh install_maplibre-native.sh
./install_tilemaker.sh
./install_maplibre-native.sh
```
Далее необходимо проверить папки стилей. Если папки стилей пустые, скачайте базовые стили и шрифты:

```bash
cd ../styles/
chmod +x git_clone_styles.sh
./git_clone_styles.sh
```

После установки вы можете использовать проект двумя способами:

   1. **Автоматически:** Собрать и запустить консольное приложение `maps_basic`.
   2. **Вручную:** Выполнить пошаговый процесс в консоли (описан ниже).

---

## Пошаговый процесс (Вручную)

Процесс состоит из 3 шагов: **Генерация ➡️ Настройка стилей ➡️ Рендеринг**. 
*Шаги 1 и 2 выполняются один раз. Их нужно повторять только при изменении исходных данных или путей.*

### Шаг 1: Генерация тайлов (`data/`)
Сгенерируйте векторные тайлы из файла OpenStreetMap (`.osm.pbf`).

```bash
cd data/
chmod +x make_tiles.sh
./make_tiles.sh <путь_к_osm.pbf> <папка_для_вывода>
```
*Пример:*

```bash
./make_tiles.sh /path/to/file.osm.pbf /path/to/extracted_tiles
```

**ВАЖНО!** 
Если возникают ошибки замените файлы ./data/process-coastline.lua и ./data/process-openmaptiles.lua
   
   ```bash
   cp /usr/share/doc/tilemaker/examples/process-coastline.lua ./data/process-coastline.lua
   cp /usr/share/doc/tilemaker/examples/process-openmaptiles.lua ./data/process-openmaptiles.lua
   ```
   
* **Проблема нехватки памяти (Ошибка `Killed`):** 
  По умолчанию `tilemaker` пытается загрузить и обработать все точки (`nodes`), пути (`ways`) и отношения (`relations`) прямо в оперативной памяти (RAM). На крупных регионах или странах RAM мгновенно переполняется, система принудительно убивает процесс (ошибка `Killed` от Linux OOM Killer), и скрипт `make_tiles.sh` аварийно прерывается.
* **Решение через флаг `--store <путь_к_папке>`:** 
  Чтобы избежать падения, в команду внутри `make_tiles.sh` необходимо добавить аргумент `--store` и указать <путь к временной директории> (./tmp). Это заставит утилиту сбрасывать тяжелый кэш геоданных на диск, снижая требования к RAM до минимума.
  

### Шаг 2: Подготовка и настройка стилей (`styles/`)
1. Перейдите в папку стилей. Если папки стилей пустые, скачайте базовые стили:
   ```bash
   cd ../styles/
   chmod +x git_clone_styles.sh
   ./git_clone_styles.sh
   ```

2. Настройте пути к вашим ресурсам в файлах стилей с помощью Python-скрипта:
   ```bash
   python3 ./make_static.py -t <абсолютный_путь_к_тайлам> -f <абсолютный_путь_к_шрифтам> -s <абсолютный_путь_к_спрайтам>
   ```
   
   
   *Пример:*
   
   ```bash
   python3 ./make_static.py 
      -s /home/alina/Documents/projects/tile_maps_basic/styles/data/sprite 
      -f /home/alina/Documents/projects/tile_maps_basic/styles/data/openmaptiles-fonts/fonts/ 
      -t /home/alina/Documents/projects/tile_maps_basic/data/tiles/
   ```
   
   **Справка по параметрам `make_static.py`:**
   
   * `-t, --tiles` — абсолютный путь к папке с векторными тайлами (из Шага 1).
   * `-f, --fonts` — абсолютный путь к папке со шрифтами (glyphs).
   * `-s, --sprite` — абсолютный путь к папке и имени файла спрайтов (без расширения).
   * `-h, --help` — показать справку.
   
   
#### Редактирование стилей

При необходимости редактирования базового стиля и его последующего сохранения используйте следующий веб-ресурс:

https://maplibre.org/maputnik/?layer=1912726243%7E0#7.37/50.124/15.372

**ВАЖНО!** 
Полученный стиль необходимо сохранить под именем style.json в папку с другими стилями (или в её дочернюю директорию),
после чего запустить скрипт из шага 2 подпункта 2.


### Шаг 3: Рендеринг карты
Для отрисовки карты используйте утилиту `mbgl-render` (установленную на этапе инициализации):

**Пример команды рендеринга по границам области:**

```bash
mbgl-render -s styles/dark-matter-gl-style/style.json --bounds="57.2 23.4 56.7 24.8" -w 1024 -h 1024 -o map.png # Latvia
mbgl-render -s styles/dark-matter-gl-style/style.json --bounds="54.3 27.1 53.7 27.8" -w 1024 -h 1024 -o map.png # Minsk
```

**Основные параметры `mbgl-render`:**

*   `-s, --style` — путь к файлу стиля (сконфигурированному на Шаге 2).
*   `-o, --output` — имя выходного файла изображения (например, `map.png`).
*   `-w, --width` — ширина изображения в пикселях.
*   `-h` или `--height` — высота изображения в пикселях (Внимание! Одиночный флаг `-h` здесь задает высоту, а не справку).
*   `--bounds` — границы области. Формат строго: `"север запад юг восток"` (градусы через пробел).
*   `-z, --zoom` / `-x, --lon` / `-y, --lat` — альтернативный способ позиционирования по центру и масштабу вместо `--bounds`.
*   `--debug` — режим отладки. **Также добавляет отладочную информацию(границы тайлов) на само изображение.**
*   `--help` — показать полную справку по утилите.
